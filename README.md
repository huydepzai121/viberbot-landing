# ViberVN Bot Landing

Vietnamese landing page for [ViberVN Bot](https://github.com/nullmastermind/vibervn-bot-releases) — Next.js (App Router) + Tailwind + [shadcn/ui](https://ui.shadcn.com), static export.

## Develop

```bash
npm install
npm run dev
```

## Build static site

```bash
npm run build   # writes to out/
```

Serve `out/` with any static host (nginx on the VPS uses port 8082).
