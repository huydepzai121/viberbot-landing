Remote gateway cho phép ứng dụng desktop đăng nhập vào một **ViberVN Host** (ví dụ [host.codefuel.space](https://host.codefuel.space)) thay vì chỉ chạy bot trên máy của bạn. Chat, mô hình, lịch tự động và kênh nhắn tin tiếp tục chạy trên Host.

## Bạn cần gì?

- Ứng dụng ViberVN Bot bản mới nhất (tải ở [trang chủ](/#download)).
- Địa chỉ Host, ví dụ `https://host.codefuel.space`.
- Tài khoản trên Host (do quản trị viên cấp, hoặc bạn nhận mã mời).

## Các bước kết nối

<Steps>
  <Step title="Mở ứng dụng và chọn Remote gateway">
    Trong phần kết nối, chọn chế độ **Remote gateway** (không dùng máy cục bộ).
  </Step>
  <Step title="Nhập Remote URL">
    Điền đúng địa chỉ Host, gồm `https://`, không thêm dấu `/` thừa ở cuối nếu ứng dụng tự chuẩn hoá. Ví dụ: `https://host.codefuel.space`.
  </Step>
  <Step title="Đăng nhập">
    Bấm **Sign in with your identity provider** (hoặc nút đăng nhập tương đương). Cửa sổ **Sign in to ViberVN Bot gateway** mở trang `/login` của Host. Nhập tên đăng nhập và mật khẩu, rồi bấm **Đăng nhập**.
  </Step>
  <Step title="Kiểm tra Cài đặt">
    Vào **Cài đặt → Model → Model chính**. Trang phải tải được danh sách model (không còn báo “Tải cài đặt thất bại”). Nếu chưa có khóa mô hình, đặt khóa của bạn trên Host (mỗi người dùng có khóa riêng).
  </Step>
  <Step title="Chọn nơi máy tính chạy">
    Sau khi đăng nhập, mở phần **Máy tính của bot** và chọn một trong các chế độ:

    | Chế độ | Máy chạy ở đâu | Tắt PC thì sao? |
    |---|---|---|
    | **Sandbox trên Host / VPS** (Local VM khi đang nối Remote gateway) | Container Docker trên VPS Host | **Vẫn chạy.** Bot, phiên, lịch tự động và máy tính tiếp tục trên Host. Ứng dụng desktop chỉ là client, mở lại là thấy trạng thái mới. |
    | **SSH / Cloud / VPS của bạn** | Máy hoặc container bạn đăng ký qua SSH | Dừng khi máy đó tắt. |
    | **PC của bạn / Local VM trên máy bạn** | Máy đang mở ứng dụng | Dừng khi tắt máy hoặc đóng app. |

    Image sandbox (`vibervnbot-sandbox:desktop`) có môi trường desktop (trình quản lý file, Chromium/Chrome, terminal) cho chế độ Docker.
  </Step>
</Steps>

<Tip>
  Đăng nhập dùng cookie phiên `vibervnbot_session_at` trên HTTPS. Nếu cửa sổ đăng nhập hiện JSON `{"detail": "Not Found"}`, Host chưa có trang `/login` — cần bản Host v0.2.0 trở lên. Sandbox trên Host (chạy khi tắt máy) cần Host **v0.3.0** trở lên.
</Tip>

## Máy tính chạy ở đâu?

| Lựa chọn | Hành vi | Tắt PC |
|---|---|---|
| Sandbox trên Host / VPS (Docker) | Container biệt lập trên VPS, image desktop (file manager, Chrome, terminal) | Vẫn chạy |
| SSH / Cloud 24/7 | Máy bạn đã đăng ký (host, user, khóa) | Dừng khi máy đó tắt |
| VPS (SSH) + container | Container Docker trên máy chủ của bạn, cùng image Local VM | Dừng khi máy chủ đó tắt |
| PC / Local VM trên máy bạn | Máy đang mở app | Dừng khi tắt máy |
| This device trên Host | Không dùng — đó là hệ điều hành dùng chung của VPS | — |

## Vẫn dùng hoàn toàn trên máy bạn (Local gateway) {#local-gateway}

Bạn không bắt buộc phải dùng Host. Trong **Cài đặt → Gateway**, chọn **Local** (không nhập Remote URL). Ứng dụng chạy backend ngay trên máy bạn như trước: chat, Local VM (Docker trên máy bạn), PC này, lịch tự động — tất cả ở local, không cần `host.codefuel.space`. Tắt máy thì bot local dừng, đúng như bản desktop thông thường.

Remote gateway chỉ là thêm lựa chọn khi bạn muốn bot chạy trên VPS lúc tắt máy.
