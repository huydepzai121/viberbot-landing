Trang quản trị của ViberVN Host cho phép admin tạo tài khoản, phát mã mời, khóa/mở người dùng và xem thông tin máy SSH đã đăng ký.

- Địa chỉ: [https://host.codefuel.space/admin](https://host.codefuel.space/admin)
- Đăng nhập trước tại [https://host.codefuel.space/login](https://host.codefuel.space/login)

## Đăng nhập

1. Mở `/login`.
2. Nhập tên đăng nhập và mật khẩu admin.
3. Bạn sẽ vào `/admin` (hoặc trang “Đã đăng nhập” rồi bấm **Mở trang quản trị**).

Chỉ tài khoản vai trò **admin** mới vào được `/admin`. Tài khoản thường sẽ thấy thông báo không có quyền.

## Việc admin làm được

- **Người dùng:** xem danh sách, tạo tài khoản (user hoặc admin), khóa hoặc mở khóa.
- **Mã mời:** tạo mã dùng một lần (mặc định 72 giờ). Mã chỉ hiện một lần khi tạo — gửi cho người mới để họ đăng ký.
- **Kết nối desktop:** chọn sandbox trên Host/VPS (chạy khi tắt máy), SSH, hoặc PC/Local VM trên máy bạn (dừng khi tắt máy).

## Tạo tài khoản từ dòng lệnh

Trên máy chủ cài Host:

```bash
docker compose -f docker-compose.prod.yml exec host \
  python -m vibervn_host.cli admin create-user --username tenban --role admin --password-file /run/pw
```

Đổi mật khẩu:

```bash
docker compose -f docker-compose.prod.yml exec host \
  python -m vibervn_host.cli admin set-password --username tenban --password-file /run/pw
```

Mật khẩu tối thiểu 10 ký tự. Không đưa mật khẩu vào lệnh không có file, và không commit file mật khẩu.
