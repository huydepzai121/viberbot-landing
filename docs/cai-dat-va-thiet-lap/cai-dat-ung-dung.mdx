Bấm biểu tượng bánh răng để mở **Cài đặt**.

{/* IMG:settings */}

## Các nhóm cài đặt

| Nhóm | Có gì |
|---|---|
| **Model** | Mô hình mặc định, mô hình phụ cho các việc nhỏ, mô hình cho bot phụ |
| **Nhà cung cấp** | Tài khoản, khóa API, endpoint tuỳ chỉnh và mô hình cục bộ |
| **Trò chuyện** | Hiện hoặc ẩn phần suy nghĩ của mô hình và các tuỳ chọn hiển thị |
| **Giao diện** | Chủ đề màu, sáng/tối, phông chữ, mở lại cuộc trò chuyện gần nhất khi khởi động |
| **Không gian làm việc** | Thư mục làm việc mặc định của bot |
| **An toàn** | Quy tắc phê duyệt và giới hạn |
| **Bộ nhớ & ngữ cảnh** | Cách bot ghi nhớ và làm gọn hội thoại dài |
| **Giọng nói** | Nhận dạng giọng nói và đọc to câu trả lời |
| **Nâng cao** | Giữ máy tính thức và các tuỳ chọn cho người dùng nâng cao |
| **Công cụ & khóa** | Bật tắt công cụ và khóa cho các dịch vụ đi kèm |
| **Gateway** | Kết nối tới máy chủ khác và **Truy cập web** |
| **Kho bảo mật** | Thông tin đăng nhập, thẻ, liên hệ để bot điền biểu mẫu |
| **Thông báo**, **Phím tắt**, **Giới thiệu** | Thông báo hệ thống, phím tắt, phiên bản ứng dụng |

## Những tuỳ chọn hay dùng

<AccordionGroup>
  <Accordion title="Đổi mô hình mặc định">
    **Model** → chọn nhà cung cấp và mô hình → bấm **Áp dụng**. Cuộc trò chuyện mới sẽ dùng mô hình này.
  </Accordion>
  <Accordion title="Giữ máy không ngủ khi bot đang làm">
    **Nâng cao → Giữ máy tính thức**, chọn **Khi đang làm việc** (mặc định) hoặc **Luôn luôn**. Màn hình vẫn có thể tắt; gập laptop vẫn làm máy ngủ.
  </Accordion>
  <Accordion title="Đổi giao diện sáng/tối và chủ đề">
    **Giao diện** → chọn chủ đề. Bạn có thể tìm và cài thêm chủ đề màu từ VS Code Marketplace.
  </Accordion>
  <Accordion title="Ẩn phần suy nghĩ của mô hình">
    **Trò chuyện → Reasoning Blocks**, tắt để chỉ xem câu trả lời.
  </Accordion>
</AccordionGroup>
