Bấm tên hồ sơ ở góc dưới bên trái (mặc định là **default**) rồi chọn **Cài đặt**. Ô **Tìm kiếm** ở trên cùng giúp tìm nhanh một tuỳ chọn.

<Frame caption="Cài đặt › Model › Model chính">
  <img src="/images/24-settings-model.png" alt="Cửa sổ Cài đặt, mục Model chính" />
</Frame>

## Các nhóm cài đặt

| Nhóm | Có gì |
|---|---|
| **Model** | Model chính, model dự phòng, model phụ trợ, agent con và **Nhà cung cấp** (khóa API, endpoint tuỳ chỉnh) |
| **Trò chuyện** | Tính cách mặc định, múi giờ, bật tắt khối suy luận, tệp đính kèm |
| **Giao diện** | Ngôn ngữ, chủ đề Sáng/Tối/Hệ thống, kiểu chữ, cửa sổ & bố cục |
| **Không gian làm việc** | Thư mục làm việc và cách tìm dự án trên máy |
| **An toàn** | Khi nào bot phải hỏi bạn trước khi làm việc có rủi ro |
| **Browser** | Hồ sơ trình duyệt của bot, nơi giữ các phiên đăng nhập |
| **Kho bảo mật** | Thông tin bot được phép dùng để điền biểu mẫu, liên kết trình quản lý mật khẩu |
| **Bộ nhớ & ngữ cảnh** | Bật tắt bộ nhớ lâu dài và cách làm gọn hội thoại dài |
| **Giọng nói** | Trò chuyện bằng giọng nói, nhận dạng giọng nói, đọc to câu trả lời |
| **Nâng cao** | Giữ máy tính thức, chạy lại phần làm quen và tuỳ chọn cho người dùng nâng cao |
| **Thông báo** | Cảnh báo và âm thanh trên máy tính |
| **Gateway** | Máy chủ ViberVN Bot mà ứng dụng đang kết nối |
| **Phím tắt** | Xem và đổi phím tắt |
| **Công cụ & khóa** | Bật tắt từng công cụ, thêm khóa cho công cụ cần |
| **Phiên** | Tự lưu trữ cuộc trò chuyện cũ, xem cuộc trò chuyện đã lưu trữ |
| **Giới thiệu** | Phiên bản và cập nhật |

## Những tuỳ chọn hay dùng

<AccordionGroup>
  <Accordion title="Đổi mô hình mặc định">
    **Model → Model chính** → chọn **Nhà cung cấp** và **Model** → bấm **Áp dụng**. Cuộc trò chuyện mới sẽ dùng model này. Muốn đổi model chỉ cho cuộc trò chuyện đang mở, bấm tên model ở ô nhắn tin.
  </Accordion>
  <Accordion title="Giữ máy không ngủ khi bot đang làm">
    **Nâng cao → Desktop & khởi động → Giữ máy tính thức**, chọn **Tắt**, **Khi đang làm việc** hoặc **Luôn luôn**. Màn hình vẫn có thể tắt; gập laptop vẫn làm máy ngủ.
  </Accordion>
  <Accordion title="Đổi giao diện sáng/tối và chủ đề">
    **Giao diện → Chủ đề** → chọn **Sáng**, **Tối** hoặc **Hệ thống** (theo máy).
  </Accordion>
  <Accordion title="Ẩn phần suy nghĩ của mô hình">
    **Trò chuyện → Hành vi → Khối suy luận**, tắt để chỉ xem câu trả lời.
  </Accordion>
  <Accordion title="Đổi ngôn ngữ giao diện">
    **Giao diện → Chung → Ngôn ngữ** → chọn **Tiếng Việt** hoặc ngôn ngữ khác.
  </Accordion>
</AccordionGroup>
