ViberVN Bot không đi kèm mô hình AI riêng. Bạn chọn nhà cung cấp mình muốn và trả phí trực tiếp cho họ (hoặc dùng mô hình miễn phí chạy trên máy).

## Lần đầu mở ứng dụng

Màn hình **Hãy thiết lập ViberVN Bot cho bạn** hỏi bạn muốn dùng nhà cung cấp nào. Đăng nhập tài khoản, hoặc bấm **Tôi đã có khóa API**, chọn nhà cung cấp, dán khóa vào ô **Dán khóa API** (chưa có thì bấm **Lấy khóa**) rồi bấm **Kết nối**. Chưa có sẵn khóa thì bấm **Tôi sẽ chọn nhà cung cấp sau** để thiết lập sau.

  <img src="/images/02-onboarding-api-key.png" alt="Chọn nhà cung cấp và dán khóa API" />

## Đổi mô hình mặc định

Mở **Cài đặt → Model → Model chính**, chọn **Nhà cung cấp** và **Model** rồi bấm **Áp dụng**. Mô hình này được dùng cho cuộc trò chuyện mới, việc chạy theo lịch và các bot phụ.

<Frame caption="Cài đặt › Model › Model chính">
  <img src="/images/24-settings-model.png" alt="Cài đặt Model chính" />
</Frame>

## Đổi mô hình cho một cuộc trò chuyện

Bấm vào tên mô hình trong ô nhắn tin (bên trái nút micro) để chọn mô hình khác chỉ cho cuộc trò chuyện đang mở. Ô **Tìm model** giúp tìm nhanh, ngôi sao cạnh một mô hình đánh dấu nó là yêu thích.

<Tip>
Đổi mô hình giữa một cuộc trò chuyện dài làm lần trả lời tiếp theo tốn phí hơn, vì mô hình mới phải đọc lại toàn bộ hội thoại. Với việc mới, mở cuộc trò chuyện mới sẽ tiết kiệm hơn.
</Tip>

## Các nhà cung cấp phổ biến

| Nhà cung cấp | Cách kết nối | Ghi chú |
|---|---|---|
| OpenAI | Khóa API | Lấy khóa ở trang quản lý API của OpenAI |
| Anthropic | Khóa API | Lấy khóa ở Anthropic Console |
| Google Gemini | Khóa API | Lấy khóa ở Google AI Studio |
| OpenRouter | Khóa API | Một khóa dùng được nhiều mô hình của nhiều hãng |
| xAI Grok | Đăng nhập tài khoản | Đăng nhập qua trình duyệt |
| Ollama | Chạy trên máy | Miễn phí, dữ liệu không rời khỏi máy, cần máy đủ mạnh |
| Endpoint tuỳ chỉnh | Địa chỉ + khóa | Bất kỳ dịch vụ nào tương thích OpenAI hoặc Anthropic |

## Thêm hoặc đổi khóa API

Mở **Cài đặt → Model → Nhà cung cấp → Khóa API** để thêm hoặc thay khóa. Mục **Endpoint tuỳ chỉnh** ngay bên dưới dùng cho dịch vụ tương thích OpenAI hoặc mô hình tự chạy.

<Frame caption="Cài đặt › Model › Nhà cung cấp › Khóa API">
  <img src="/images/25-settings-providers-api-keys.png" alt="Cài đặt khóa API cho nhà cung cấp" />
</Frame>

<Note>
Khóa API được lưu trên máy của bạn. Đừng chia sẻ khóa cho người khác. Nếu nghi ngờ khóa bị lộ, hãy thu hồi nó ở trang của nhà cung cấp và tạo khóa mới.
</Note>
