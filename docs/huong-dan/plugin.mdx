Bấm **Plugin** ở cuối thanh bên trái để mở cửa sổ quản lý tiện ích. Cửa sổ này có các tab:

| Tab | Dùng để |
|---|---|
| **Kết nối** | Nối bot với ứng dụng bạn dùng (email, lịch, lưu trữ, công cụ làm việc) |
| **Kỹ năng** | Bật, tắt kỹ năng đã có và cài thêm kỹ năng từ danh mục có sẵn bằng nút **Cài đặt** |
| **Nhắn tin** | Thiết lập Telegram, Zalo và các kênh khác. Xem [Nhắn tin](/nhan-tin/tong-quan) |
| **Tiện ích mở rộng** | Plugin bổ sung tính năng cho ứng dụng |

## Danh mục plugin

Danh mục plugin là danh sách các plugin đã được kiểm duyệt, chia theo nhóm (Bộ nhớ, Desktop, Nền tảng nhắn tin, Web và trình duyệt, Công cụ, Giọng nói, Tự động hóa, Mô hình). Mỗi plugin ghi rõ nó kết nối tới đâu và cần thông tin gì. Plugin chỉ được cài khi bạn bấm cài.

<Warning>
Plugin của cộng đồng do bên thứ ba duy trì. Chỉ cài plugin bạn tin tưởng và đọc kỹ phần mô tả về dữ liệu mà plugin gửi đi.
</Warning>
