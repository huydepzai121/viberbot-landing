Có gì mới

Tóm tắt từ ghi chú phát hành chính thức trên GitHub Releases (đi cùng bản tải tại get.viber.vn).

Dạy một việc (Teach a task)

Trong Show computer, thêm ghi chú tùy chọn rồi Start: bạn điều khiển trình duyệt trong khung đỏ; mọi click, gõ phím và đổi trang được ghi kèm ảnh. Mật khẩu / OTP / thẻ được ghi ở dạng ẩn. Khi Stop, agent biến bản ghi thành skill đã lưu và báo tên skill.

Bằng chứng làm việc trên trình duyệt

Khi agent dùng trình duyệt trong một câu trả lời, ảnh chụp tab hiện dưới tin nhắn — bấm để phóng to, hoặc mở Show computer từ liên kết.

Trình duyệt giữ đăng nhập

Mỗi bot có một hồ sơ trình duyệt bền; trình duyệt local còn mở khoảng 30 phút idle — đăng nhập và trang đang mở được giữ giữa các việc. Agent có thể đóng đúng trình duyệt nó mở (không tắt nhầm desktop app).

Cài đặt

Hướng dẫn theo hệ điều hành

Nội dung lấy từ get.viber.vn — giữ nguyên các lệnh PowerShell / shell chính thức.

Windows 11 22H2+

Tải chứng chỉ và file .msix. Tin cậy chứng chỉ một lần trong PowerShell chạy bằng quyền Administrator:

Import-Certificate -FilePath .\ViberVN-signing.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople

Rồi mở file .msix và chọn Install.

macOS 13+

Mở .dmg và kéo ứng dụng vào Applications. Lần đầu macOS sẽ chặn: System Settings → Privacy & Security → Open Anyway, hoặc:

xattr -dr com.apple.quarantine "/Applications/ViberVN Bot.app"

Nếu vẫn báo ứng dụng bị hỏng, tự ký một lần:

codesign --force --deep --sign - "/Applications/ViberVN Bot.app"

Linux

chmod +x file .AppImage đúng kiến trúc rồi chạy nó.

chmod +x VibervnbotBundled-*-linux-x86_64.AppImage ./VibervnbotBundled-*-linux-x86_64.AppImage

FAQ

Câu hỏi thường gặp

App chạy ở đâu?

Trên máy bạn (self-hosted): desktop, terminal và các nền tảng nhắn tin — đúng mô tả tại get.viber.vn. Free yêu cầu máy đang bật. Cloud Coming soon sẽ always-on.

Vì sao OS cảnh báo khi cài?

Bộ cài chưa được ký bởi nhà phát hành tin cậy; mỗi hệ điều hành cảnh báo một lần. Làm theo hướng dẫn Cài đặt (chứng chỉ Windows / Open Anyway trên macOS / chmod AppImage trên Linux).

Cài Windows thế nào?

Tải .msix và ViberVN-signing.cer từ get.viber.vn. Trong PowerShell Administrator: Import-Certificate -FilePath .\ViberVN-signing.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople, rồi mở .msix → Install.

macOS báo hỏng / bị chặn?

Privacy & Security → Open Anyway, hoặc xattr -dr com.apple.quarantine "/Applications/ViberVN Bot.app". Nếu vẫn hỏng: codesign --force --deep --sign - "/Applications/ViberVN Bot.app".

Cập nhật có mất dữ liệu không?

Không. Tải bản mới và cài đè; dữ liệu & cấu hình được giữ. Nếu thiếu/hỏng runtime, cài lại từ get.viber.vn.

Tôi dùng model nào?

Tự gắn key/endpoint. Provider có sẵn hoặc custom OpenAI-compatible.

Có Telegram / nhắn tin không?

Có — gateway nhắn tin (Telegram đã dùng phổ biến). CLI còn helper cho nền tảng khác.
